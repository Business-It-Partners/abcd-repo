# Dental OS — Why Dental OS

**Baseline:** V1, 2026-10-15. Target architecture; implementation status is tracked separately.

Dental OS gives clinic users a predictable working environment for our existing Dental SaaS. Users enter one workspace, find their tools, move between tasks, and receive improvements without having to manage browser tabs as their working environment.

The product value is continuity, discoverability, controlled application delivery, and clear recovery. Wallpaper, dock artwork, and motion support that value; resemblance to a general desktop is not the acceptance criterion.

The host OS remains responsible for hardware, drivers, native processes, and system facilities. Dental OS organizes our first-party tools above it. No dental module contents are specified by this platform contract.

The separate Flutter/Rust company OS provides engineering references, not requirements or dependencies. Dental OS deliberately uses independently delivered web bundles and the existing SaaS authority rather than a local pharmacy engine.

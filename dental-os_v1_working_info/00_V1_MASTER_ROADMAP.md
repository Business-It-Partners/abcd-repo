**Purpose:** execution map for the OS platform and its first-party app delivery milestones. Baseline: 2026-10-15; milestone sequence amended 2026-10-19, 2026-10-20, 2026-10-21 and 2026-10-22.

- This roadmap defines dependencies and milestone order; [global status](00_V1_STATUS.md) records progress.

M17 app work may proceed before M15 closes; final G14 integrated acceptance still requires verified G15.

## Execution policy

One active platform milestone by default. M15 remains the platform closeout track. M17 is the user-directed app-delivery track and, by explicit direction, uses the existing M15 worktree rather than a separate worktree. M17 source is the app code integrated in the M15 worktree, the corresponding Dental SaaS behavior references and the current M15 SDK/platform contract. It has no ongoing app-code, branch or worktree dependency on another Dental OS milestone. Residual M12/G12 and M13/G13 evidence remains owned by those records and is coordinated through M15.4. Reconcile existing work when a milestone begins; close applicable exit gates before starting dependent implementation. Current milestone authorization/status is recorded in global status. The user gives standing authorization to commit/push milestone work for verification and merge each verified milestone into main without another confirmation, preserving its branch and checkpoint tags. Follow the [integration policy](../docs/GIT_AND_CI_SETUP.md). This does not authorize production promotion, history rewriting or remote provisioning by itself.

Statuses: PLANNED, IMPLEMENTING, IMPLEMENTED, VERIFIED, BLOCKED, DEFERRED, REMOVED. Technical verification and user acceptance are separate. A missing required supported-host check prevents verification of that scope; an explicit scope change needs a recorded user decision and updated traceability.

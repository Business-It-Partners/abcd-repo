## App scope

The app implements the SaaS Treatment Progress worklist with the Dental OS shared UI and SDK. The API returns the server-calculated projection for active patients with open cases and non-cancelled plans that contain at least one pending stage. Each row includes the completed/total stage count, assigned doctors, outstanding balance, and next pending return date. The app supports patient/record/plan/doctor search, doctor filtering, sortable paginated rows, and refresh.

The renderer calls only `GET /v1/treatment-progress` through `ClinicClient`; it has no direct HTTP, credentials, or local authoritative data store. The host requires the `treatment_progress.access` clinic capability before dispatching the route. The SaaS service remains authoritative for tenant scoping and business data. Patient-detail navigation is omitted because the OS has no approved cross-app navigation contract.

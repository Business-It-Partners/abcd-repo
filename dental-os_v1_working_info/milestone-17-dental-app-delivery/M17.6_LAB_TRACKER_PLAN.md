# M17.6 Plan — Lab Tracker and Lab Supplier Record

**Status:** PLANNED. App source has not yet been imported into M17.
**Package:** company.dental.lab-tracker

## App scope

Bring over both same-package modules:

- **Lab Tracker:** order/request list and detail, assignment, status progression, receive/fit confirmation, notes, and audited cancellation as supported by SaaS.
- **Lab Supplier Record:** supplier directory, add/edit/status, supplier history, and links to lab orders where supported by SaaS.

## SDK and acceptance focus

- Verify the exact SaaS API contract, permissions, supplier relationship, row revisions, and cancellation semantics. Use only Dental OS SDK calls.
- Test order creation/assignment/progression/cancellation, supplier changes/history, audit/refresh, denied roles/tenant, and stale-revision conflicts with synthetic data.
- Confirm module selection stays within one package/window and uses the shared OS module explorer. Switching modules must not lose the other module's state or create a second app identity.
- Verify dirty forms, idempotent writes, unknown outcomes, keyboard/focus, and staging Store installation/update.

Do not create a local supplier source of truth or duplicate Finance business rules.

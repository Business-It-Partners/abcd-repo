# M17.7 Plan — Finance

**Status:** PLANNED. App source has not yet been imported into M17.
**Package:** company.dental.finance

## App scope

Bring over all eight SaaS modules in the existing Finance package:

1. Transaction Record
2. Patient payments
3. General expenses
4. Salary payments
5. Product list
6. Purchases
7. Supplier list
8. Supplier payments

## SDK and acceptance focus

- Build a route/method/query/payload/role inventory from the current SaaS source for all eight modules before enabling writes. Use only the Dental OS SDK.
- Verify totals and displayed summaries against synthetic source records; test create/edit/correction/void behavior only where SaaS defines it, with audit and refresh.
- Exercise module-specific roles, salary and supplier restrictions, tenant denial, stale-row conflicts, idempotency, uncertain outcomes, and multi-step write recovery.
- Confirm all eight modules remain inside one package and managed window, with the shared explorer and truthful dirty-form state.
- Validate bounded/paginated data, compact layout, keyboard/focus, and staging Store install/update.

No local ledger, recalculated authoritative balance, or app-side bypass of SaaS finance rules is allowed.

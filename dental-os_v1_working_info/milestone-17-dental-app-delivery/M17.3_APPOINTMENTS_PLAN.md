## Current SaaS API contract reviewed

Source pin: Dental SaaS f0d059d36540b4b6907cace089085ce0df62d454. Exact reviewed source files and blob hashes are recorded in [SOURCE_IMPORT.json](../../apps/dental-apps/company.dental.appointments.m17/SOURCE_IMPORT.json).

| Operation | Route | Contract used by the app |
| --- | --- | --- |
| Day schedule | GET /v1/appointments?date=YYYY-MM-DD[&doctorName=…] | Date-only clinic-local day; doctor filter is optional |
| Range schedule | GET /v1/appointments?bucket=today\|week\|upcoming\|cancelled&today=YYYY-MM-DD[&doctorName=…] | Worker defines the range and returns no more than its bounded response |
| Summary | GET /v1/appointments/summary?today=YYYY-MM-DD | Returns todayBooked, thisWeekBooked, upcomingBooked, and cancelled |
| Doctor references | GET /v1/clinic/staff-references | Select active rows whose staffType is doctor |
| Book | POST /v1/appointments | Name, optional phone, doctor name, date, start minute, duration and reason; Idempotency-Key is host-mediated |
| Reschedule/edit | PATCH /v1/appointments/:id | Full appointment fields plus expectedRowVersion; only active doctors may be selected |
| Status | POST /v1/appointments/:id/status | One of booked, arrived, cancelled, no_show, plus expectedRowVersion |

The SaaS Worker authenticates clinic access and owns branch-scoped appointment data, active-doctor validation, overlap detection, row-version conflicts, status persistence, and idempotency receipts. At the pinned source revision, the Appointments controller does not call requireClinicCapability("appointments.access"); the current SaaS role map grants this capability to admin, doctor, and reception. The app and Dental OS broker enforce the signed app/module and session-capability checks, but a future restriction by role also requires Worker enforcement. Record this boundary; do not claim the Worker independently denies a role. The UI's same-doctor overlap warning uses only the currently loaded list and is advisory; every write is checked by the Worker. Dates remain ISO date-only values, and today is derived using the clinic session timezone.

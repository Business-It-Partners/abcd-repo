## App scope

The implementation follows the maintained Dental SaaS Calendar module using Dental OS's shared Bikram Sambat date utilities and `ClinicClient`. The view includes month navigation, day selection, shared task counts, a selected-day task sheet, task creation, completion/reopen, archive, refresh, loading/error/empty states, and dirty-draft protection. The SaaS API stores Gregorian AD ISO dates; the app converts month/day labels at the UI boundary. A BS month's AD range is at most 32 days and is checked against the SDK route's 45-day maximum.

The pinned SaaS contract supports list, create, status change, and archive. It does **not** expose a task-edit endpoint, so the app does not offer local-only task editing. It uses `expectedRowVersion` and SDK idempotency keys for mutations, refreshes canonical data on conflicts, retries the same immutable command after an uncertain result, and keeps clinic business data out of local storage.

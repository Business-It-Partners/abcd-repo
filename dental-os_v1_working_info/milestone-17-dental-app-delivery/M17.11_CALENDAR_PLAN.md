# M17.11 Plan — Calendar

**Status:** PLANNED. App source has not yet been imported into M17.
**Package:** company.dental.calendar

## App scope

Bring over the SaaS calendar and task workflows: bounded date-range reads, month/day navigation, task create/edit/complete/archive, and saved state as supported by the current SaaS contract.

## SDK and acceptance focus

- Verify the current API method/query and timezone/date rules through the Dental OS SDK. Test Bikram Sambat/Gregorian conversion and month/year boundaries against authoritative fixtures.
- Verify date-range caps, task create/edit/complete/archive, role/tenant denials, stale revisions, idempotency, uncertain outcomes, and refresh.
- Preserve unsaved day drafts and dirty-form behavior across navigation, module switching, and managed-window close decisions.
- Test loading/empty/error states, keyboard/focus, narrow layouts, and Store install/update with synthetic tasks only.

Do not claim a local calendar is authoritative when the SaaS source is unavailable; no hidden write queue is allowed.

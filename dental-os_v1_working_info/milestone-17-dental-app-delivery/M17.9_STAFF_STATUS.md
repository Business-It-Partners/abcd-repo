## Local salary-history fix — 2026-10-25 (not published)

The Staff app rejected valid salary payouts whose `payPeriod` used the Worker's zero-padded `YYYY-MM` format for January through September. Its previous validator accepted unpadded months but rejected canonical values such as `2026-09`, causing the entire history request to fail. The local M15 source now uses the same `YYYY-MM` validation as Finance. Seven Staff package tests, package typecheck/build, root build, 502 root tests, and docs validation pass. The signed 1.0.3 staging package and running OS are unchanged; this source fix has not been published or installed.
